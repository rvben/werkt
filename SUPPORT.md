# Support

Werkt is pre-1.0 open-source software maintained on a best-effort basis. It does
not currently include commercial support, uptime commitments, or emergency
operational response.

Use GitHub issues for reproducible bugs, documentation defects, and focused
feature proposals. Include the Werkt commit or version, operating system,
executor, PostgreSQL version, relevant configuration with secrets removed, and
the smallest reproduction you can provide.

Do not use public issues for vulnerabilities. Follow
[SECURITY.md](SECURITY.md) instead.

Questions about private deployments should be reduced to a generic,
reproducible example. Maintainers cannot inspect private infrastructure or
recover credentials, keys, retained artifacts, or databases on a user's behalf.
