Plan → apply

Two explicit decisions

Deletion only begins after an operator or agent has seen the exact candidates and names the plan to apply.

PLANSelect

Group shared paths, apply age and per-automation count floors, and persist relative storage keys with byte estimates.

15 MINReview

The plan remains inspectable but expires quickly, limiting drift between what was reviewed and what will execute.

APPLYRevalidate

Recompute eligibility so a new retry, run, deployment, or rollback can protect previously selected material.

COMMITDetach

Clear database references only if the final SQL guard still sees no active consumer, then remove the owned direct-child path.

AUDITRecord

Persist deleted, skipped, and failed outcomes. Repeated apply requests return the same terminal plan.
