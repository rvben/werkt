One-way path

Set, bind, resolve, erase

Management sees names and versions. Only an execution attempt receives plaintext, and only through an explicit manifest binding.

SETAccept once

The CLI reads a pipe or environment variable and refuses a visible terminal, keeping values out of arguments and shell history.

SEALEncrypt

AES-256-GCM uses a fresh random nonce and binds ciphertext to the secret name as authenticated data.

BINDPin intent

Deployment verifies every named secret and records the revision-to-secret relationship transactionally.

RUNResolve late

Process and Husker runners fetch only the current attempt’s references and inject values under their declared environment names.

MASKRedact first

Plaintext, URL, JSON, and base64 forms are replaced before truncation, persistence, and error reporting.
